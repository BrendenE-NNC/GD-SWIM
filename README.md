# GD Swim

A Hypixel Skyblock mod for Stuff (I) Wanted In Mods (SWIM).

## The Problem

In Hypixel Skyblock, modifications to the base game (mods) are common tools used to improve the game experience, and provide quality of life, but many of these mods are missing features that would be extremely convenient to have, such as timers for daily tasks. Creating a mod to fill these gaps would be extremely convenient, and would improve general quality of life.

## How It Works

This mod includes feature(s?) that improve your quality of life in Skyblock, help you progress, and make the game more enjoyable overall, with a focus on features not found in other mods.

## Tech Stack

- **Language:** Java
- **Libraries:** Depends on Fabric API Mod
- **External tools:** Hypixel Modding API, INtelliJ.

## Setup

Download .jar file, place inside of mods folder of your Fabric Minecraft instance with Fabric API Installed.

## Usage

Launch the Minecraft instance with the game installed and join Hypixel Skyblock. Run /gdswim for help.
